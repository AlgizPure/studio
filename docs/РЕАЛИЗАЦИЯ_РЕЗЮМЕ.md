### ✅ Модуль 3: Streak UI (100%)

**Созданные файлы:**
- `src/components/habit-streak-card.tsx` - Детальная карточка стрика
- `src/components/freeze-streak-dialog.tsx` - Диалог заморозки
- `src/components/streaks-dialog.tsx` - Главный диалог стриков

**Реализованные функции:**
- ✅ Отображение текущего стрика
- ✅ Рекорд (лучший стрик)
- ✅ Habit Strength Score (HSS) с визуализацией
- ✅ Статистика за 90 дней
- ✅ Процент завершения
- ✅ Consistency score
- ✅ Управление skip tokens
- ✅ Заморозка стрика (до 14 дней)
- ✅ Валидация дат заморозки
- ✅ Пресеты заморозки (3/7/14 дней)
- ✅ Визуальные progress indicators

**Метрики:**
- **HSS Formula**: 
  ```
  0.3 * (currentStreak/30) + 
  0.4 * completionRate90d + 
  0.2 * consistencyScore + 
  0.1 * (longestStreak/100)
  ```

**Skip Tokens:**
- 2 токена в месяц по умолчанию
- Обновляются 1-го числа
- Использование без ломания стрика

**Freeze:**
- Максимум 14 дней
- Раз в квартал
- Идеально для отпусков/болезней

## 💡 Ключевые инновации

### 1. **Swipeable Cards**
Первый habit tracker с полноценной поддержкой свайп-жестов:
- Touch и mouse support
- Визуальный feedback
- Smooth animations
- Threshold-based triggering

### 2. **Habit Strength Score (HSS)**
Более честная метрика, чем просто стрики:
- Учитывает текущий стрик
- Процент завершения за 90 дней
- Consistency (стабильность)
- Исторический рекорд

### 3. **Time-based Grouping**
Автоматическая группировка по времени суток:
- Определяется по timeWindow
- Collapsible sections
- Individual progress bars
- Smart organization

### 4. **Streak Freeze**
Гуманный подход к стрикам:
- Заморозка для отпусков/болезней
- Skip tokens без штрафа
- Grace period
- Сохранение мотивации
