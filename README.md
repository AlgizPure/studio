# Zenith Trainer 🏋️

**Zenith Trainer** — это современное веб-приложение для отслеживания тренировок и привычек, созданное с использованием Next.js, Firebase и Genkit AI. Оно предназначено для пользователей, которые хотят систематизировать свои тренировки, отслеживать прогресс и получать интеллектуальные рекомендации для достижения своих фитнес-целей.

## 🚀 Основные возможности

*   **Конструктор тренировок:** Создавайте сложные тренировки с настраиваемыми циклами (обычные, суперсеты, дроп-сеты), упражнениями, повторениями, весами и временем отдыха.
*   **Программы тренировок:** Объединяйте тренировки в структурированные программы с определенной продолжительностью и расписанием.
*   **Отслеживание привычек:** Создавайте и отслеживайте ежедневные или еженедельные привычки, устанавливайте цели и следите за сериями (streaks).
*   **Интеллектуальный анализ (AI):**
    *   **Оптимизатор расписания:** Получайте персональные рекомендации по недельному расписанию на основе ваших целей и предпочтений.
    *   **Анализ прогрессии:** AI анализирует ваши прошлые тренировки и предлагает, как увеличить вес или изменить повторения для дальнейшего прогресса.
    *   **Инсайты:** Приложение генерирует полезные выводы и предупреждения на основе ваших логов активности.
*   **Гибкое расписание:** Планируйте тренировки и привычки по дням недели, "каждые N дней" или как отдельные события.
*   **Кастомизация:** Создавайте собственные библиотеки упражнений и категорий.

## 🛠️ Технологический стек

*   **Фреймворк:** [Next.js](https://nextjs.org/)

*   **AI-интеграции:** [Google Genkit](https://firebase.google.com/docs/genkit)
*   **UI-компоненты:** [shadcn/ui](https://ui.shadcn.com/)

## ⚙️ Установка и запуск

### Предварительные требования

*   [Node.js](https://nodejs.org/) (версия 18+)
*   [npm](https://www.npmjs.com/) или [yarn](https://yarnpkg.com/)

### Локальный запуск

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <URL репозитория>
    cd <имя папки>
    ```

2.  **Установите зависимости:**
    ```bash
    npm install
    ```

3.  **Настройте переменные окружения:**
    Создайте файл `.env.local` в корне проекта. Для локальной разработки без реальных учетных данных Firebase можно использовать моковые данные:
    ```env
    NEXT_PUBLIC_AI_MOCK=1

    # Заполните этими значениями, если у вас нет реального проекта Firebase
    NEXT_PUBLIC_FIREBASE_API_KEY="your_mock_api_key"
    NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN="your_mock_auth_domain"
    NEXT_PUBLIC_FIREBASE_PROJECT_ID="your_mock_project_id"
    NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET="your_mock_storage_bucket"
    NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID="your_mock_sender_id"
    NEXT_PUBLIC_FIREBASE_APP_ID="your_mock_app_id"
    ```
    Для полной функциональности (включая AI-функции) вам потребуется настроить проект Firebase и заполнить файл `.env.local` реальными учетными данными.

4.  **Запустите приложение:**
    ```bash
    npm run dev
    ```
    Приложение будет доступно по адресу [http://localhost:3000](http://localhost:3000).

## 🗂️ Структура проекта

*   `src/app/`: Основные страницы и маршрутизация Next.js App Router.
*   `src/ai/`: Логика, связанная с Genkit AI, включая "флоу" (flows) для генерации инсайтов и рекомендаций.
*   `src/components/`: Основные UI-компоненты React.
    *   `src/components/ui/`: Компоненты из библиотеки shadcn/ui.
    *   `src/components/workout-builder/`: Компоненты для создания и редактирования тренировок.
    *   `src/components/workout-execution/`: Компоненты для режима выполнения тренировки.
*   `src/firebase/`: Настройка Firebase, провайдеры контекста и хуки для взаимодействия с Firestore.
*   `src/hooks/`: Пользовательские хуки React.
*   `src/lib/`: Вспомогательные функции, утилиты, определения типов и основная бизнес-логика.
*   `src/styles/`: Глобальные стили и конфигурация Tailwind CSS.
