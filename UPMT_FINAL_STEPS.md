## 🔧 НАСТРОЙКА CURSOR (ОБЯЗАТЕЛЬНО)

### Шаг 1: Копирование .cursorrules в корень проекта

Cursor автоматически читает `.cursorrules` из **корня проекта**.

**Проверь наличие файла:**

```bash
# Должен существовать
ls -la .cursorrules
```

**Если файл НЕ существует, скопируй:**

```bash
# Из корня проекта (если UPMT еще не удалена)
cp UPMT/structure-templates/AI_INSTRUCTIONS/.cursorrules.template .cursorrules

# Проверь
ls -la .cursorrules
```

---

### Шаг 2: Проверка содержимого .cursorrules

**Прочитай файл:**

```bash
cat .cursorrules
```

**Должен содержать:**
- AUTO-GENERATED секцию с данными проекта
- Правила для всех модулей
- Ссылки на документацию

**Если файл пустой или содержит только template:**
1. Перейди в папку `UPMT/structure-templates/AI_INSTRUCTIONS/`
2. Прочитай `.cursorrules.template`
3. Заполни AUTO-GENERATED секцию данными из `.upmt/metadata.yaml`

---

### Шаг 3: Тестирование Cursor

**Создай тестовый файл:**

```bash
# Создай файл test.md в корне проекта
echo "# Test file" > test.md
```

**Открой в Cursor и проверь:**
- Автодополнение работает
- Правила применяются
- Ссылки на документацию корректны

## 🆘 ПРОБЛЕМЫ И РЕШЕНИЯ

### Проблема: AI не следует правилам
**Решение:**
1. Проверь `.cursorrules` в корне проекта
2. Убедись что файл содержит AUTO-GENERATED секцию
3. Перезапусти IDE

### Проблема: Ссылки на документацию не работают
**Решение:**
1. Проверь что папка `docs/` существует
2. Убедись что пути в `.cursorrules` корректны
3. Перечитай документацию

### Проблема: Не помню где что находится
**Решение:**
1. Прочитай `BOOTSTRAP_REPORT.md`
