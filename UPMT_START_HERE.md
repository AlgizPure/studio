# 👋 START HERE

**Добро пожаловать в Universal Project Management Template!**

Система для превращения хаотичных идей проекта в структурированную, production-ready документацию за один день с помощью AI-автоматизации.

---

## 🎯 ЧТО ЭТО?

**Основные возможности:**
- 📋 Автоматическая генерация полной проектной документации
- 🤖 AI-оптимизация (Claude Code, Cursor)
- 🔍 Верификация технологического стека (актуальность 2025)
- 📊 Встроенные системы отслеживания прогресса
- 💾 Сохранение контекста между сессиями

## 🚀 БЫСТРЫЙ СТАРТ

### 1️⃣ Подготовь данные

Собери все материалы проекта и положи в `00_RAW_DATA_TEMPLATE/`:
- 💬 Чаты с AI (ChatGPT, Claude, Gemini)
- 📄 Документы (Google Docs, Notion)
- 📝 Заметки, идеи
- 💻 Код (если есть)

**Минимум:** 1-2 файла с описанием идеи (500+ слов)

### 3️⃣ Что дальше?

**Вариант A: Короткая команда (рекомендуется)**
```
Прочитай и выполни: UPMT/start/1.X.md
```
Claude прочитает алиас → загрузит оркестратор → запустит процесс

**Вариант B: Полный промпт**
- Скопируй содержимое из `UPMT/prompts/scenarios/1.X-*.md`
- Вставь в Claude Code

**Затем:**
1. **Ответь** на вопросы Claude (10-15 минут)
2. **Жди** завершения bootstrap (2-4 часа, автономно)
3. **Настрой** AI ассистентов → [UPMT_FINAL_STEPS.md](UPMT_FINAL_STEPS.md)

**Claude Code автоматически:**
- 📖 Прочитает все твои данные
- 🎯 Задаст 5-10 уточняющих вопросов
- 🔍 Проверит актуальность технологий (2025)
- 📝 Сгенерирует полную документацию (~7000+ строк)
- ✅ Подготовит проект к разработке

## ❓ ЧАСТО ЗАДАВАЕМЫЕ ВОПРОСЫ

### Q: Нужно ли заполнять metadata.yaml вручную?
**A:** Нет! Claude Code заполнит его автоматически (режим AUTO-FILL v1.0.1+).

### Q: Что если у меня мало данных?
**A:** Минимум: 1-2 файла с описанием идеи (500+ слов). Claude Code задаст вопросы для недостающей информации.

### Q: Сколько времени займёт bootstrap?
**A:**
- Ваше активное время: ~30-60 минут (ответы на вопросы, tech verification)
- Claude Code работает: 2-4 часа (автономно)
- Очистка проекта: ~10 минут (опционально, PHASE 9)
- **Итого:** Один день работы

### Q: Можно использовать Cursor вместо Claude Code CLI?
**A:** Да! Cursor работает так же, как CLI. Используй те же промпты.

### Q: Что если технологии в моих чатах устарели?
**A:** Claude Code автоматически проверит актуальность и порекомендует обновления (2025).

### Q: Обязательно ли выполнять PHASE 9 (очистку проекта)?
**A:** Нет, опционально. PHASE 9 удаляет временные файлы UPMT (~XX MB), оставляя только файлы для разработки. Рекомендуется для чистоты проекта.
