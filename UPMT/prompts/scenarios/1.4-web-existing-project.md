## ТВОЯ ЗАДАЧА

Выполни полный bootstrap процесс с анализом существующего кода через GitHub API.

## ИНСТРУКЦИИ ПО ВЫПОЛНЕНИЮ

### ШАГ 1: Прочитай архитектурные файлы через GitHub API

**1.1: Прочитай оркестратор:**
```bash
gh api /repos/{owner}/{repo}/contents/UPMT/prompts/orchestrator.md --jq '.content' | base64 -d
```

**1.2: Прочитай Web адаптер:**
```bash
gh api /repos/{owner}/{repo}/contents/UPMT/prompts/adapters/web-adapter.md --jq '.content' | base64 -d
```

---

### ШАГ 2: Установи параметры сценария

```yaml
scenario:
  name: "Web + Existing Project"
  code: "1.4"
  mode: "WEB_GITHUB"
  existing_project: true
  
data_sources:
  - raw_data: "UPMT/bootstrap/00_RAW_DATA_TEMPLATE/ (через GitHub API)"
  - code_analysis: true
  - code_location: "src/, app/, components/ (через GitHub API)"
  
github:
  repo: "{owner}/{repo}"
  api_mode: true
```
