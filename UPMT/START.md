## ❓ НЕ УВЕРЕН КАКОЙ СЦЕНАРИЙ?

### Вопрос 1: Где работаешь?
- **Локально (терминал/Cursor)** → CLI сценарии (1.1 или 1.2)
- **В браузере (claude.ai)** → Web сценарии (1.3 или 1.4)

### Вопрос 2: Есть ли код?
- **Да, код уже есть** → Существующий проект (1.2 или 1.4)
- **Нет, только идеи/чаты** → Новый проект (1.1 или 1.3)

## 📚 ЧТО ДАЛЬШЕ?

После выбора сценария:

1. **Скопируй команду** из выбранного сценария выше
2. **Вставь** в Claude Code (CLI) или Cursor
3. **Жди** - Claude автоматически:
   - 📖 Прочитает все данные
   - 🎯 Задаст 5-10 уточняющих вопросов
   - 🔍 Проверит актуальность технологий (2025)
   - 📝 Сгенерирует полную документацию
   - ✅ Подготовит проект к разработке

**Время выполнения:**
- Ваше активное время: ~30-60 минут (ответы на вопросы)
- Claude работает: 2-4 часа (автономно)

## 🔧 ТЕХНИЧЕСКАЯ ИНФОРМАЦИЯ

### Архитектура промптов:

```
UPMT/
├── START.md                    # ← ВЫ ЗДЕСЬ (интерактивное меню)
│
├── start/                      # Короткие алиасы (50 строк)
│   ├── 1.1.md                  # CLI + Новый
│   ├── 1.2.md                  # CLI + Существующий
│   ├── 1.3.md                  # Web + Новый
│   └── 1.4.md                  # Web + Существующий
│
└── prompts/
    ├── orchestrator.md         # Главный оркестратор
    │
    ├── phases/                 # Общие фазы (переиспользуемые)
    │   ├── phase-1-analysis.md
    │   ├── phase-2-interview.md
    │   ├── phase-3-tech-verification.md
    │   ├── phase-4-synthesis.md
    │   ├── phase-5-documentation.md
    │   ├── phase-5.5-design.md
    │   ├── phase-5.7-backend.md
    │   ├── phase-6-setup.md
    │   ├── phase-7-validation.md
    │   ├── phase-8-report.md
    │   └── phase-9-cleanup.md       # (optional)
    │
    ├── adapters/               # Специфичные инструкции
    │   ├── cli-adapter.md      # Для локальной работы
    │   └── web-adapter.md      # Для GitHub API
    │
    └── scenarios/              # Полные сценарии (150-180 строк)
        ├── 1.1-cli-new-project.md
        ├── 1.2-cli-existing-project.md
        ├── 1.3-web-new-project.md
        └── 1.4-web-existing-project.md
```

### Преимущества модульной архитектуры:

✅ **Короткие команды** - алиасы по 50 строк
✅ **Переиспользование** - фазы используются во всех сценариях
✅ **Легкое обновление** - изменения в одном файле применяются везде
✅ **Checkpoint система** - автосохранение после каждой фазы
✅ **Масштабируемость** - легко добавить новые сценарии
✅ **Полная совместимость** - сохранен весь функционал старого промпта
