Следуй оркестратору (`UPMT/prompts/orchestrator.md`), выполняя фазы последовательно:

5. **PHASE 5:** Documentation (через GitHub API)

7. **PHASE 5.7:** Backend (conditional)
8. **PHASE 6:** Setup Instructions
9. **PHASE 7:** Validation
10. **PHASE 8:** Final Report
11. **PHASE 9:** Project Cleanup (optional - информация в конце PHASE 8)

**⚠️ КРИТИЧНО:**
- Используй Web адаптер для всех файловых операций
- ВСЕ операции через GitHub API (GET/PUT requests)
- Коммить каждый файл отдельно
- Показывай прогресс каждые 30 минут
