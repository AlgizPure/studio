**ШАГ 3: Установи параметры сценария**

```yaml

  name: "CLI + New Project"
  code: "1.1"
  mode: "CLI"
  existing_project: false
  
data_sources:
  - raw_data: "UPMT/bootstrap/00_RAW_DATA_TEMPLATE/"
  - code_analysis: false
```

---

**ШАГ 4: НАЧИНАЙ ВЫПОЛНЕНИЕ**

Следуй оркестратору (`UPMT/prompts/orchestrator.md`), выполняя фазы последовательно:

1. **PHASE 1:** Analysis (raw data only)
2. **PHASE 2:** Interview
3. **PHASE 3:** Tech Verification
4. **PHASE 4:** Synthesis
5. **PHASE 5:** Documentation
6. **PHASE 5.5:** Design (conditional)
7. **PHASE 5.7:** Backend (conditional)
8. **PHASE 6:** Setup Instructions
9. **PHASE 7:** Validation
10. **PHASE 8:** Final Report
11. **PHASE 9:** Project Cleanup (optional - информация в конце PHASE 8)

**⚠️ КРИТИЧНО:**
- Используй CLI адаптер для всех файловых операций
- Коммить после каждой фазы (checkpoint system)
- Показывай прогресс каждые 30 минут
